## Dataset Access: Labeled-Dementia

This project makes use of the Labeled-Dementia dataset from the DementiaBank corpus, which is part of the broader TalkBank system. Please note that this dataset is restricted and not publicly available for direct download.

To gain access, you must become a member of TalkBank. This involves contacting Prof. Brian MacWhinney at macw@cmu.edu. In your request, be sure to include your academic affiliation, postal address, and email address. Additionally, you should describe how you plan to use the data and, if applicable, mention whether you may be able to contribute to the database in the future.

If you are a student, please note that access to password-protected data requires supervision. Your faculty advisor must apply for membership themselves and take responsibility for the data usage.

Once your membership is approved, you will be provided with credentials to access the dataset through the DementiaBank portal at https://dementia.talkbank.org.
